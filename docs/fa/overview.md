# راهنمای جامع معماری و توسعه DeviceHub (نسخه 1.1.0)
توسعه و نگهداری: **پارسا فتحی**

پروژه **DeviceHub** یک پلتفرم یکپارچه برای مدیریت ناوگان اینترنت اشیاء (IoT)، دروازه مرزی (Edge Gateway)، تحلیل بلادرنگ داده‌های حسگرها و عیب‌یابی هوشمند است. این مستند راهنمای سریع معماری، پروتکل و مسیر توسعه امن پروژه را تشریح می‌کند.

---

## ۱. ساختار سرویس‌ها و جریان داده

1. **لایه دستگاه‌ها و شبیه‌ساز (Edge Simulation & Devices):**
   - پشتیبانی از پروتکل باینری اختصاصی C11 با چک‌سام CRC32 جهت ارسال کارآمد داده روی پهنای باند کم.
   - شبیه‌ساز ناوگان با ۶ سناریوی تله‌متری (پایدار، خطای ناگهانی، نوسان مقادیر، قطعی موقت و...).

2. **بروکر پیام (MQTT Broker):**
   - مدیریت ارتباطات مبتنی بر رویداد در تاپیک‌های ساختاریافته (`device/{id}/telemetry`، `device/{id}/status`، `device/{id}/command`).

3. **دروازه مرزی (Edge Gateway):**
   - بافر محلی روی پایگاه داده SQLite با قابلیت WAL جهت جلوگیری از دست رفتن داده‌ها در قطعی‌های طولانی تا زمان برقراری مجدد ارتباط با سرور مرکزی.
   - تشخیص و حذف پیام‌های تکراری بر اساس شناسه پیام (`msgId`) و حفظ زمان ثبت در مبدأ.

4. **موتور تحلیل داده و یادگیری ماشین (Analytics / ML Service):**
   - پیاده‌سازی سرویس با FastAPI برای شناسایی بی‌درنگ ناهنجاری‌ها (Isolation Forest و Z-Score) و دسته‌بندی انحرافات مقادیر تله‌متری.

5. **دستیار عیب‌یابی و هوش مصنوعی:**
   - موتور مشاوره‌ای مبتنی بر شواهد ثبت‌شده در سیستم؛ خروجی‌ها همراه با استناد به شناسه‌های هشدار و معیارهای عددی ارائه شده و هیچ دستور خودکاری بدون تأیید مستقیم اپراتور صادر نمی‌شود.

---

## ۲. بهبودهای امنیتی اعمال شده در نسخه ۱.۱.۰

- **مدیریت نشست و احراز هویت سرویس‌ها:** لزوم ارسال توکن‌های اعتبارسنجی داخلی بین وب‌سرویس و سرویس‌های کمکی.
- **اعتبارسنجی ساختاریافته پاسخ‌های هوشمند:** محدودسازی خروجی عیب‌یابی برای ارجاع دقیق به تله‌متری‌های مستند و تفکیک پیشنهادها از داده‌های قطعی حسگرها.
- **پایداری پایگاه داده:** حذف گزینه‌های خطرناک بازنویسی بدون کنترل دیتابیس در محیط توسعه و تولید.

## ۳. نحوه راه‌اندازی محلی

```bash
# نصب وابستگی‌ها
bun install

# آماده‌سازی دیتابیس
bun run db:generate
bun run db:push

# بررسی نوع‌داده‌ها و عدم وجود خطای تایپ
bun run typecheck

# اجرای برنامه
bun run dev
```
